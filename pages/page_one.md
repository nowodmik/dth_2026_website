# Advantages of Open Source Software

Open source software is software whose source code is publicly available and can be used, modified, and shared under an open source license. By contrast, closed source software keeps its source code private, and only the original authors, companies, or other authorised parties can legally inspect, copy, or alter the code. These differences give open source software several advantages.

One of the main advantages of open source software is collaboration. While closed source software is mainly developed by companies or authorised development teams, open source software allows broader participation, enabling others to contribute to its development. Contributors can identify bugs, suggest improvements, and help make the software more useful for different users.

Another advantage is transparency, which allows users to examine how a program works and check whether it functions as intended, especially when problems arise. This transparency can also support reproducibility by helping researchers understand the methods used and reproduce results.

In addition to collaboration and transparency, open source software can reduce reliance on specific companies. If developers disagree with how a project is managed, they can fork the original project to create an independent one. For example, LibreOffice was established in 2010 as an independent, community-driven project based on OpenOffice.org.

Overall, open source software offers several advantages to individual users, researchers, organisations, and developers by enabling collaboration, verification, and independent development.
