# Disadvantages of Open Source Software

Open source software can be a double-edged sword, offering both advantages and disadvantages. Although open source software allows broader participation, some projects rely on only a few developers or volunteers for maintenance. Unlike proprietary software, which often provides professional technical support, some open source projects may lack such support. Even if the software itself is free, maintaining it still requires time, effort, and resources.

This openness can also be taken advantage of by attackers. In March 2024, a hidden backdoor was discovered in XZ Utils. The project had been maintained mainly by a single unpaid volunteer, Lasse Collin. A contributor using the name Jia Tan began helping with the project in 2021, gradually gained trust, and was granted co-maintainer access during 2022-2023. Jia Tan then inserted malicious code, which could allow attackers to gain unauthorised access to affected systems. This incident shows that excessive trust in contributors can make open source projects vulnerable, so it is necessary to review code changes carefully and strengthen security measures.

Having access to the source code does not necessarily mean participating in the decision-making process. For example, many developers contribute to the Linux kernel, but Linus Torvalds is responsible for merging changes into its mainline repository. A strong leader can help a project develop in a consistent direction, but even an experienced leader can make poor decisions. Therefore, users and developers should be aware of these disadvantages when using or contributing to open source software.
